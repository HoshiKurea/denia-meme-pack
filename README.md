# 达妮娅 AstrBot 表情资源包

![预览](previews/cover.png)

收录 **934张**去重后的达妮娅相关表情，按 **21个类别**整理，保留原始GIF/PNG/JPEG/WebP文件。处理范围为[呜哇小站](https://emoji.wuwa.games/tags/character-daniya)公开API列出的32个相关专辑，不声称覆盖整个互联网。

## 安装

在表情包管理插件「从GitHub安装」中填写：

- 仓库：`HoshiKurea/denia-meme-pack`
- 分支：`master`
- 包所在目录：`.`

安装后在「设置中心 → 使用规则」绑定人格或会话并保存。普通分类模式可直接使用；逐图索引附来源标签，语义模式如需更细的视觉描述可在插件内进一步处理。本仓库不携带向量模型或服务商配置。

主要根据原素材动作标签分类，模糊标签和混合角色条目另作预览复核。`misc`用于未能明确判定情绪的图片；来源标签不是逐帧视觉描述。
